==========================================
HR Timesheet Sheet: Table Transparency Fix
==========================================

* Fixes the styles in timesheet filling view so that if you have a lot of
  rows for different tasks, the header and footer rows don't appear on
  top of the actual timesheet rows.


Configuration
=============

* None needed

Usage
=====

* Fill in timesheets as usual in the Summary view.
