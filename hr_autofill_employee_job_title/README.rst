===========================
Hr Autofill Employee Job Title
===========================
Automatically fill a employee job title, when creation is done via portal 
expense reporting.

Installation
============
* Install the module

Configuration
=============
* In the Settings -> Employees, configure the automatic job title

Usage
=====
* Install module
* Configure the job title in the settings
   * Add new titles in Employee -> Settings -> Job Titles, if needed
* Add employees from the portal
* Added employees get the title set in the settings
