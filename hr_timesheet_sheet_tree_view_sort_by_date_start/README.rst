================================================================
HR Timesheet Sheet – Sort sheets by Date From field in tree view
================================================================

This module improves how sheets are shown by sorting them by their Date From
field in tree view. Then new timesheet sheets are always shown in the top
of the tree view.

Configuration
=============
No configuration needed

Usage
=====
Just install this module from Apps and see how list view differs from earlier view

Known issues / Roadmap
======================
There are no known issues with this module
